# Readme10 - 확장 로드맵 및 실무 적용 시나리오

## 0. 구현 완료 (주식투자/자산운용 도메인 확장)
- **애널리스트 리포트 추천 추출 + 컨센서스**: `/analyst-report`, `/analyst-report/pdf`, `/analyst-consensus/{ticker}` (`server/analyst.py`, Postgres 저장)
- **콜센터(AICC) 통화 QA 어시스턴트**: `/call-summary`, `/call-summary/{call_id}` (`server/callcenter.py`, Postgres 저장). 실시간 착신/IVR/CTI/상담원 배분은 범위 밖 — 통화 녹음을 사후 업로드하는 방식만 지원
- **글로벌 마켓 대시보드**: `/market-overview` (`server/market.py`, `server/market_data.py`) — 원화 기준 주요국 환율, 세계 시간대(프론트엔드 계산), 주요국 주가지수. 무료 공개 API 기반, 실거래/투자 판단용 아닌 참고용
- 음성(STT) → 요약 자동화 파이프라인은 이미 `/transcribe-and-report`, `/call-summary`로 구현됨(과거 "장기 로드맵" 항목이었던 부분)

## 1. 단기 로드맵(1~2개월)
- API 응답 표준화 및 에러 코드 정비
- 종목 마스터를 정적 시드(`tickers_kr.json`)에서 실제 KRX 종목마스터 연동으로 교체
- 컴플라이언스 키워드 목록(금지어/필수고지)을 컴플라이언스 팀 검토 기반으로 정교화

## 2. 중기 로드맵(3~6개월)
- 벡터 DB 연동으로 회의록/리포트 검색/질의응답 구축
- 사용자/조직 단위 권한 관리 도입
- 콜 QA 이력(`call_summaries`) 기반 상담원별/기간별 QA 대시보드
- 실시간 시세 연동(현재는 추출/집계만 지원, 시세 조회는 범위 밖)

## 3. 장기 로드맵(6개월~)
- 사내 데이터 기반 도메인 특화 파인튜닝
- 대시보드 기반 회의/상담 생산성 분석(팀별/기간별)
- 콜센터 텔레포니(IVR/CTI/실시간 스트리밍) 연동 검토 — 별도 인프라 프로젝트로 분리 필요

## 4. 실무 적용 패턴

### 패턴 A: 팀 단위 회의 자동 정리
- 회의 종료 후 텍스트 업로드
- 3분 내 요약/액션아이템 공유
- 누락 과제 방지 및 결정 이력 축적

### 패턴 B: 기술 조직 지식 검색
- 임베딩 저장 후 유사 회의 검색
- 과거 의사결정 재활용으로 중복 논의 감소

### 패턴 C: 운영 리스크 모니터링
- 회의록 분류 결과 기반 부정/리스크 신호 감지
- 콜 QA 컴플라이언스 플래그(금지어/필수고지 누락) 기반 상담 리스크 조기 감지
- 이슈 확산 전 조기 대응

### 패턴 D: 애널리스트 리포트 컨센서스 트래킹
- 여러 증권사 리포트를 텍스트/PDF로 누적 입력
- 종목별 목표주가 평균/의견 분포로 의사결정 참고자료 생성

## 5. 결론
AI-Meeting-Summarizer의 기술 스택은 “빠른 도입 + 점진적 확장”에 최적화되어 있습니다. 초기에는 로컬 CPU 기반 경량 운영으로 시작했고, 애널리스트 리포트/콜센터 QA 도메인을 별도 모듈로 얹어 확장했습니다. 다음 단계는 실시간 시세/종목마스터 연동과 컴플라이언스 룰 고도화입니다.
